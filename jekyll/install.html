Installing qspec

The easiest way to install qspec is to run:

pip install qspec

We recommend creating a virtual environment before installing via pip, see the official guide.

Alternatively, qspec can be installed from source by cloning or downloading from the GitHub repository or by using pip to install directly from source with:

pip install git+https://github.com/patmlr/qspec.git



Dependencies

The qspec package has the following dependencies of standard scientific packages which are automatically installed along with it when using pip:

  • Matplotlib
  • NumPy
  • SciPy
  • SymPy

Parts of the qspec package currently are only available for 64-bit Windows systems. Support for macOS and Linux systems is planned in the future. The 64-bit limitation is imposed by SciPy and will most probably remain.
