Welcome to qspec's homepage

Atom/Laser physics
qspec is an atom/laser physics library with a broad range of physical, mathematical and data processing functions and frameworks.
Performant
qspec utilizes the numpy.ndarray class and C++ to ensure fast calculations of large data samples.
Modular fit models
A framework to construct arbitrary fit models in a modular way facilitates analysing data across many science fields.
Coherent interactions
An object-oriented simulation framework written in C++ provides solvers for coherent and dissipative laser-atom interactions without the need to deal with mathematics.
