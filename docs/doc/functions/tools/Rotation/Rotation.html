qspec. Rotation  (  alpha=0.0 ,  dr=None  )[source]

A rotation in 3d-space, defined by an angle and a rotation axis, see rotation_matrix.

Parameters:
alphascalar

The angle of the rotation (rad).

drscalar_nd | None

The rotation axis. If None, the $z$-axis is used.

Attributes:
Rndarray

The rotation matrix.

alphascalar

The angle of the rotation (rad).

alpha_degscalar

The angle of the rotation (deg).

drndarray

The normalized rotation axis.

Raises:
ValueError

If dr is not a 3d-vector.
