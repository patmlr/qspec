qspec. merge_dicts  (  a ,  b ,  path=None  )[source]

Recursively merge the dictionary b into the dictionary a. Values of b override those of a.

Parameters:
adict

The first dict.

bdict

The second dict.

pathlist | None

The keys of the current recursion level, used internally.

Returns:
adict

b merged into a.
