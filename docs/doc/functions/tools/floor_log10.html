qspec. floor_log10  (  x  )[source]

The integer part of the logarithm to the base 10, $\lfloor\log_{10}|x|\rfloor$. Zeros are mapped to 0.

Parameters:
xarray_like

Scalar values.

Returns:
nndarray

The closest integer values below the logarithm to the base 10 of the absolute value of x.
