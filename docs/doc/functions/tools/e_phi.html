qspec. e_phi  (  theta ,  phi ,  axis=-1  )[source]

The azimuthal unit vector of the orthonormal system defined by e_r

$$ \hat{e}_\phi = \begin{pmatrix}0\\ \cos(\phi)\\ -\sin(\phi)\end{pmatrix}. $$
Parameters:
thetaarray_like

The angle $\theta$ (rad).

phiarray_like

The angle $\phi$ (rad).

axisint

The axis along which the vector components are aligned.

Returns:
e_phindarray

The unit vector $\hat{e}_\phi$.
