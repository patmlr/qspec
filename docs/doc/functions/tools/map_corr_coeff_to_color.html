qspec. map_corr_coeff_to_color  (  val ,  clip=True  )[source]

Maps a value between -1 and 1 to a red-to-green colormap.

Parameters:
valscalar

A value between -1 and 1.

clipbool

Whether to clip vals outside -1 and 1. If False, raise ValueError.

Returns:
(r, g, b)tuple[int, int, int]

A tuple of RGB values in the range 0-255.
