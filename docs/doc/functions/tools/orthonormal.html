qspec. orthonormal  (  r ,  axis=-1  )[source]

An orthonormal system with the first vector pointing in the direction of r.

Parameters:
rarray_like

The first vector of the orthonormal system. Does not have to be normalized.

axisint

The axis along which the vector components are aligned.

Returns:
(r1, r2, r3)tuple[ndarray, ndarray, ndarray]

Three orthonormal vectors.

Raises:
ValueError

If r does not have 3 components along the specified axis.
