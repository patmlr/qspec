qspec. e_theta  (  theta ,  phi ,  axis=-1  )[source]

The polar unit vector of the orthonormal system defined by e_r

$$ \hat{e}_\theta = \begin{pmatrix}\cos(\theta)\\ -\sin(\theta)\sin(\phi)\\ -\sin(\theta)\cos(\phi)\end{pmatrix}. $$
Parameters:
thetaarray_like

The angle $\theta$ (rad).

phiarray_like

The angle $\phi$ (rad).

axisint

The axis along which the vector components are aligned.

Returns:
e_thetandarray

The unit vector $\hat{e}_\theta$.
