qspec. COLORS  (   )[source]

ANSI escape sequences to print colored text in the console, see print_colored.

Attributes:
BOLD'\x1b[1m'

Bold text.

ENDC'\x1b[0m'

Resets the color and the style.

FAIL'\x1b[91m'

Red.

HEADER'\x1b[95m'

Pink.

OKBLUE'\x1b[94m'

Blue.

OKCYAN'\x1b[96m'

Cyan.

OKGREEN'\x1b[92m'

Green.

UNDERLINE'\x1b[4m'

Underlined text.

WARNING'\x1b[93m'

Yellow.
