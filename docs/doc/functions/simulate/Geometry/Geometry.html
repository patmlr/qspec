qspec.simulate. Geometry  (   )[source]

A fluorescence detection geometry. The solid angle over which fluorescence light is detected can be defined through intervals of the two angles $\theta$ and $\phi$, see Geometry.set_intervals. With these, every spatial direction can be addressed using an orthonormal system defined by

$$ \hat{e}_r = \begin{pmatrix}\sin(\theta)\\ \cos(\theta)\sin(\phi)\\ \cos(\theta)\cos(\phi)\end{pmatrix}. $$

If a rotation with the matrix $R$ is specified, see Geometry.set_rotation, the new system is $\hat{e}_r^\prime = R \hat{e}_r$. The entire two-dimensional interval is defined through the Cartesian product $\bigcup_i \theta_i \times \bigcup_i \phi_i$. For every disjoint interval, a weight can be defined, see Geometry.set_weights, and a probability density function can be defined for continuous angle weights, see Geometry.set_pdf. A sample of angle pairs from the defined intervals can be generated with Geometry.integration_sample. By default, the complete solid angle is covered.
