qspec.simulate.Geometry. set_intervals  (  theta ,  phi  )[source]

Set the intervals of the angles $\theta$ and $\phi$. Overlapping intervals are merged and the covered solid angle Geometry.solid_angle is calculated.

Parameters:
thetaarray_like

An interval or a list of intervals for the angle $\theta$ (rad).

phiarray_like

An interval or a list of intervals for the angle $\phi$ (rad).

Raises:
ValueError

If theta or phi is neither an interval nor a list of intervals.
