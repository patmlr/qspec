qspec.simulate.Geometry. integration_sample  (  step=None  )[source]

Sample the defined intervals with equidistant values for numerical integration. All intervals are exactly covered by an odd number of values (for Simpson integration) at the expense of not matching the step size exactly.

Parameters:
stepscalar | None

The approximate spacing between the equidistant values of the integration sample (rad). If None, Geometry.step is used. The default value is $\pi/32$.

Returns:
(theta, phi)tuple[list[ndarray], list[ndarray]]

Two lists of arrays with equidistant values in the defined intervals for $\theta$ and $\phi$, respectively.
