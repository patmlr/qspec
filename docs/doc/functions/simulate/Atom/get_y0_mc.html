qspec.simulate.Atom. get_y0_mc  (  n_samples=None ,  ground_state_labels=None  )[source]

The initial state vectors of the atom for the Monte-Carlo master equation solver with all ground states populated equally and random phases, see Interaction.mc_master.

Parameters:
n_samplesint | None

The number of samples to create. Must be a multiple of the number of ground states. If None, the minimum number of samples is created.

ground_state_labelsIterable[str] | str | None

An iterable of labels belonging to ground states. If None, the label of the first state Atom.states[0] is used.

Returns:
y0_mcndarray

The initial state vectors of the atom with shape (n_samples, Atom.size).

Raises:
ValueError

If n_samples is not a multiple of the number of ground states.
