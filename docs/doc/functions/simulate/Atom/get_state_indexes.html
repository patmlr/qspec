qspec.simulate.Atom. get_state_indexes  (  labels=None ,  f=None ,  m=None  )[source]

The indexes of the states with the specified labels and quantum numbers.

Parameters:
labelsIterable[str] | str | None

The labels of the states whose indexes are to be returned. If None, all labels are used.

farray_like | None

The $F$ quantum numbers whose indexes are to be returned. If None, all are used.

marray_like | None

The $m$ quantum numbers whose indexes are to be returned. If None, all are used.

Returns:
indexesndarray

The indexes corresponding to the specified labels and $F$ and $m$ quantum numbers.
