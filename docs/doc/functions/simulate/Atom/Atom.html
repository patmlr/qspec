qspec.simulate. Atom  (  states=None ,  decay_map=None ,  mass=0 ,  instance=None  )[source]

An atom and its inner structure.

Parameters:
statesIterable[State] | None

The states $|\mathrm{[label]}\pi JIFm\rangle$ of the atom.

decay_mapDecayMap | None

The DecayMap connecting the atomic states. If None, an empty DecayMap is used.

massscalar

The mass $m$ of the atom (u).

instanceAtom | C.AtomHandler.value | None

An existing Atom instance. If this is specified, the other parameters are ignored.

Attributes:
d_emndarray

Multipole transition strengths ordered by the rank $k$, starting at k = 1 (dipole).

decay_mapDecayMap

The DecayMap connecting the atomic states.

ekndarray

A map of the electric multipole orders of the transitions between the states.

emkndarray

A map of the multipole orders of the transitions between the states.

gsndarray

The indexes of the states with the same label as the first state Atom.states[0].

l0ndarray

The matrix of the partial spontaneous decay rates $\Gamma_{ij}$ between the states.

l1ndarray

The matrix of the decay rates of the coherences, derived from Atom.l0.

massfloat

The mass $m$ of the atom (u).

mkndarray

A map of the magnetic multipole orders of the transitions between the states.

sizeint

The number of states of the atom.

stateslist[State]

A list of the atom states $|\mathrm{[label]}\pi JIFm\rangle$.
