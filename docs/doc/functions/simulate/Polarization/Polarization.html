qspec.simulate. Polarization  (  vec=None ,  q_axis=2 ,  vec_as_q=True  )[source]

A polarization state of light. The property Polarization.x holds the polarization vector in Cartesian coordinates. The property Polarization.q holds the polarization vector in the helicity basis $(\vec{\sigma}^-, \vec{\pi}, \vec{\sigma}^+)$ for the given quantization axis q_axis.

Parameters:
vecarray_like | None

The complex-valued polarization vector $\vec{\varepsilon}$ of an electromagnetic wave / photon. The user input is normalized to a vector with length 1. The default value corresponds to linear polarization in $z$-direction, such that Polarization.x = [0, 0, 1] and Polarization.q = [0, 1, 0].

q_axisarray_like

The quantization axis used to transform Polarization.x and Polarization.q into each other. Must be an integer in {0, 1, 2} or a 3d-vector. The default is q_axis = 2 (z-axis).

vec_as_qbool

Whether vec is given in the helicity basis (True) or in Cartesian coordinates (False). The default is True.

Attributes:
instanceCppHandler

The wrapped C++ instance.

qndarray[complexfloating]

The complex polarization in the helicity basis $(\vec{\sigma}^-, \vec{\pi}, \vec{\sigma}^+)$.

q_axisndarray

The quantization axis.

xndarray[complexfloating]

The complex polarization in Cartesian coordinates $(\vec{x}, \vec{y}, \vec{z})$.
