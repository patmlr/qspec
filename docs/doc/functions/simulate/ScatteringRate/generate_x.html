qspec.simulate.ScatteringRate. generate_x  (  width=20.0 ,  step=None  )[source]

Generate frequencies which cover the entire spectrum.

Parameters:
widthscalar

The covered width around the resonances in natural linewidths.

stepscalar | None

The step size between generated x values (MHz). If None, a 30th of the natural linewidth. Note that between resonances, there might be a larger step.

Returns:
xarray_like

An array of frequencies which covers the entire spectrum (MHz).
