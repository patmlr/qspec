qspec.simulate.ScatteringRate. set_laser  (  laser=None  )[source]

Set the laser and update the saturation parameter and the polarization.

Parameters:
laserLaser | None

The incident laser beam. If None, a laser with the transition frequency, an intensity of $1$ and the default polarization is used.
