qspec.simulate. ScatteringRate  (  atom ,  laser=None ,  i_decay=0 ,  geometry=None ,  b=None  )[source]

The perturbative scattering rate of a closed electronic transition. The spectrum is excited by a laser with the specified polarization and recorded with a fluorescence detection region (FDR) defined by a Geometry. An external magnetic field can be defined through b.

Parameters:
atomAtom

The investigated atom. It must consist of a single closed transition between two fine-structure states, see ScatteringRate.check_atom.

laserLaser | None

The incident laser beam. If None, see ScatteringRate.set_laser.

i_decayint

The index of the transition in atom.decay_map.

geometryGeometry | None

The geometry of the FDR. If None, the complete solid angle is covered.

barray_like | None

The external magnetic field. Can be a vector or a scalar. In the latter case, the magnetic field is aligned with the $z$-axis.

Raises:
ValueError

If the atom does not fulfill the requirements.
