qspec.simulate.ScatteringRate. plot_spectrum  (  norm_to_4pi=False ,  step=None  )[source]

Plot the spectrum for the given geometry and that for the detection with the complete solid angle $4\pi$.

Parameters:
norm_to_4pibool

Whether to renormalize the spectrum of the geometry to have the same maximum as the spectrum for the detection with the complete solid angle. If True, the difference between the two spectra is plotted as well.

stepscalar | None

The step size for the integration of the scattering rate.
