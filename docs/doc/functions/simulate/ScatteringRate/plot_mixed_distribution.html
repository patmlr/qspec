qspec.simulate.ScatteringRate. plot_mixed_distribution  (  n=5 ,  mode=None ,  show=True ,  save=None  )[source]

Plot the fluorescence spectrum as a function of the frequency and the angle $\theta$ (at $\phi = 0$) and as a function of the frequency and the angle $\phi$ (at $\theta = 0$).

Parameters:
nint

2**n + 1 samples for theta and 2**(n + 1) + 1 samples for phi are drawn.

modestr | None

Either "3d" for a surface plot or anything else for a color-mesh plot.

showbool

Whether to show the plots.

savestr | None

The path where to save the plots. If None, the plots will not be saved.
