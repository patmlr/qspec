qspec.simulate. Environment  (  E=None ,  B=None ,  instance=None  )[source]

Class representing an electromagnetic environment with static electric field $\vec{E}$ and magnetic field $\vec{B}$. Currently implemented:

  • Nonlinear Zeeman effect (fully diagonalized, also affects transition strength)

Parameters:
Earray_like | None

A static electric field $\vec{E}$. (NOT IMPLEMENTED)

Barray_like | None

A static magnetic field $\vec{B}$.

instanceEnvironment | C.EnvironmentHandler.value | None

An existing Environment instance. If this is specified, the other parameters are omitted.
