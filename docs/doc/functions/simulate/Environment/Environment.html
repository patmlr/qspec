qspec.simulate. Environment  (  E=None ,  B=None  )[source]

An electromagnetic environment with static electric field $\vec{E}$ and magnetic field $\vec{B}$. Currently implemented:

  • Nonlinear Zeeman effect (fully diagonalized, also affects transition strength)
Parameters:
Earray_like | None

A static electric field $\vec{E}$. (NOT IMPLEMENTED)

Barray_like | None

A static magnetic field $\vec{B}$ (T). A scalar sets the magnitude along the current direction, which is the $z$-axis by default.

Attributes:
Bndarray

The static magnetic field $\vec{B}$ (T).

Endarray

The static electric field $\vec{E}$ (not implemented).

instanceCppHandler

The wrapped C++ instance.
