qspec.Observable. rvs  (  size=1  )[source]

Random variates of the observable. If asymmetric uncertainties are specified, a skew normal distribution is assumed. However, the ratio between the left- and right-sided uncertainty must not exceed 1.5.

Parameters:
sizeint

The number of random variates. The default is 1.

Returns:
xndarray

Random variates of the observable with the given size.
