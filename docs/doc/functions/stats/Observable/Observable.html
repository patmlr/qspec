qspec. Observable  (  x ,  std=0.0 ,  std_2=0.0 ,  label=None  )[source]

A float with a label and either a symmetric or a left- and right-sided uncertainty. The operators +, * and ** propagate the uncertainties with propagate.

Parameters:
xSupportsFloat | SupportsIndex | str | bytes | bytearray

The value of the observable.

stdscalar

The standard deviation of the observable if std_2 is 0, else the left-sided 1-sigma percentile relative to x.

std_2scalar

The right-sided 1-sigma percentile relative to x. If 0, the uncertainty is symmetric.

labelstr | None

The label of the observable.

Attributes:
estndarray | None

The parameters of a skew normal distribution estimated from the asymmetric uncertainties.

labelstr | None

The label of the observable.

poptndarray | None

The parameters of a skew normal distribution fitted to the observable, see Observable.set_popt.

stdfloat

The standard deviation, or the left-sided 1-sigma percentile relative to the value if std_2 is not 0.

std_2float

The right-sided 1-sigma percentile relative to the value. If 0, the uncertainty is symmetric.
