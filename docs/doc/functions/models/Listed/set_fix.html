qspec.models.Listed. set_fix  (  i ,  fix ,  force=False  )[source]

Set a specific parameter fix state, see Model.set_fix. Also sets the fix state of the respective submodel.

Parameters:
iint_like | str

The index (int) or the name (str) of the parameter.

fixfix_type

The new fix state of the parameter.

forcebool

Force the parameter to take exactly the new fix state. If False, the parameter is converted to the correct format.

Raises:
ValueError

If fix has the wrong format.
