qspec.models.Listed. set_val  (  i ,  val ,  force=False  )[source]

Set a specific parameter value. Also sets the value of the respective submodel.

Parameters:
iint_like | str

The index (int) or the name (str) of the parameter.

valscalar

The new parameter value.

forcebool

Force the parameter to take exactly the new value. If False, the parameter is converted to the correct format.

Raises:
ValueError

If val is not a scalar and force is False.
