qspec.models. Hyperfine  (  model ,  i ,  j_l ,  j_u ,  label=None  )[source]

A hyperfine structure model, summing the submodel $g$ over all allowed transitions $F_l\rightarrow F_u$

$$ f(x) = \sum\limits_{F_l, F_u} p_{F_lF_u}\,g(x - \Delta_\mathrm{hfs}^{F_lF_u}), $$

with the hyperfine structure shifts $\Delta_\mathrm{hfs}^{F_lF_u}$, see hf_shift. The parameters are the hyperfine structure constants Al, Bl, ... and Au, Bu, ... (up to the orders allowed by $I$ and $J$), the ratios A_ratio, ... defined as Au / Al, ..., and the intensities $p_{F_lF_u}$ named int(F_l, F_u), initialized with the Racah intensities hf_int. The first intensity is fixed by default.

Parameters:
modelModel

A submodel whose parameters are adopted by this model.

iscalar

The nuclear spin quantum number $I$.

j_lscalar

The electronic total angular momentum quantum number $J_l$ of the lower state.

j_uscalar

The electronic total angular momentum quantum number $J_u$ of the upper state.

labelstr | None

A label for the Splitter (isotope / isomer / transition).

Attributes:
descriptionstr

A description of the model hierarchy, e.g., "Offset.Summed[0].Hyperfine.Voigt".

dxfloat

A hint for an x-axis step size for a smooth display of the model.

errorstr

An error message if there is an issue with the model parameters (not implemented).

fixeslist[fix_type]

The fix states of the parameters, see Model.set_fix.

linkslist[bool]

Whether the parameters are linked to the parameters with the same name in a Linked model.

modelModel | None

The submodel.

nameslist[str]

The names of the parameters.

pdict[str, int]

A map of the parameter names to their indexes.

sizeint

The number of parameters required by the model.

typestr

The name of the model type.

valslist[float]

The current values of the parameters.
