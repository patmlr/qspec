qspec.models. HyperfineQI  (  _ ,  i ,  j_l ,  j_u ,  label=None ,  qi_path=None  )[source]

A perturbative quantum interference (QI) hyperfine-structure model

$$ f(x) = \frac{1}{\max A_F^{F^\prime}}\sum\limits_{F, F^\prime}\left[\left(A_F^{F^\prime} + B_F^{F^\prime}G\right)L(x - \Delta_{FF^\prime}) + G\sum\limits_{F^{\prime\prime} > F^\prime} C_F^{F^\prime F^{\prime\prime}}L_\mathrm{qi}(x - \Delta_{FF^\prime}, \Delta_{FF^{\prime\prime}} - \Delta_{FF^\prime})\right], $$

with the coefficients $A_F^{F^\prime}$, $B_F^{F^\prime}$ and $C_F^{F^\prime F^{\prime\prime}}$ qspec.algebra.abc, the Lorentzian $L$ and its dispersive term $L_\mathrm{qi}$ LorentzQI, the hyperfine structure shifts $\Delta_{FF^\prime}$ hf_shift and the geometry parameter $G$ (geo), based on [ R. C. Brown et al., Phys. Rev. A 87, 032504 (2013)]. The other parameters are those of Hyperfine, without the intensities.

Parameters:
_Model

Empty model parameter. This hyperfine-structure model always uses LorentzQI lineshapes. To use other lineshapes, combine it with a Convolved model.

iscalar

The nuclear spin quantum number $I$.

j_lscalar

The electronic total angular momentum quantum number $J_l$ of the lower state.

j_uscalar

The electronic total angular momentum quantum number $J_u$ of the upper state.

labelstr | None

A label for the Splitter (isotope / isomer / transition).

qi_pathstr | None

Specify a directory to save and load the calculated geometric parts of the dipole matrix elements for faster repeated calculations. These depend only on the quantum numbers i, j_l and j_u.

Attributes:
descriptionstr

A description of the model hierarchy, e.g., "Offset.Summed[0].Hyperfine.Voigt".

dxfloat

A hint for an x-axis step size for a smooth display of the model.

errorstr

An error message if there is an issue with the model parameters (not implemented).

fixeslist[fix_type]

The fix states of the parameters, see Model.set_fix.

linkslist[bool]

Whether the parameters are linked to the parameters with the same name in a Linked model.

modelModel | None

The submodel.

nameslist[str]

The names of the parameters.

pdict[str, int]

A map of the parameter names to their indexes.

sizeint

The number of parameters required by the model.

typestr

The name of the model type.

valslist[float]

The current values of the parameters.
