qspec.models. VoigtAsy  (   )[source]

An asymmetric Voigt peak function of the form

$$ f(x, \Gamma, \sigma, \alpha) = \frac{\mathrm{Re}[w(z)]}{\mathrm{Re}[w(i\Gamma/(\sqrt{8}\sigma))]}, \quad z = \frac{2x + i[\Gamma/(1 + \exp(\alpha x))]}{\sqrt{8}\sigma}, $$

with the complex Faddeeva function $w$.
