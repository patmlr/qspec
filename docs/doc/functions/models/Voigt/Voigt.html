qspec.models. Voigt  (   )[source]

A Voigt peak function of the form

$$ f(x, \Gamma, \sigma) = \frac{\mathrm{Re}[w(z)]}{\mathrm{Re}[w(i\Gamma/(\sqrt{8}\sigma))]}, \quad z = \frac{2x + i\Gamma}{\sqrt{8}\sigma}, $$

with the complex Faddeeva function $w$.
