qspec.models. VoigtDerivative  (   )[source]

The first derivative of a Voigt peak function

$$\begin{aligned} f(x, \Gamma, \sigma) &= -\frac{\sqrt{2}\delta\nu}{\sigma}\frac{\mathrm{Re}[z w(z)]} {\mathrm{Re}[w(\mathrm{i}\Gamma/(\sqrt{8}\sigma))]}, \quad z = \frac{2x + \mathrm{i}\Gamma}{\sqrt{8}\sigma}\\[2ex] \delta\nu &= 0.5346\Gamma + \sqrt{0.2166\Gamma^2 + \sigma^2}, \end{aligned}$$

with the complex Faddeeva function $w$ and the parameters Gamma (the FWHM $\Gamma$ of the Lorentzian) and sigma (the standard deviation $\sigma$ of the Gaussian).
