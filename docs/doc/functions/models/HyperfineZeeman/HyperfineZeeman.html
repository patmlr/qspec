qspec.models. HyperfineZeeman  (  model ,  i ,  j_l ,  j_u ,  gi ,  gj_l ,  gj_u ,  f_l=None ,  f_u=None ,  q=None ,  rho_ml=None ,  rho_as_par=False ,  scale_par_with_shift=None ,  linear=False ,  label=None  )[source]

A hyperfine structure model in an external magnetic field, summing the submodel over all allowed transitions $|F_lm_l\rangle\rightarrow|F_um_u\rangle$. The Zeeman shifts are calculated with qspec.physics.zeeman_linear if linear is True, else with qspec.physics.hyper_zeeman_num. The relative intensities are the Racah intensities hf_int, multiplied by the squared Clebsch-Gordan coefficients, the polarization components $q_{m_u - m_l}$ and the lower state populations $\rho(F_l, m_l)$. In addition to the parameters of Hyperfine, the magnetic field is the parameter B_field (T).

Parameters:
modelModel

A submodel whose parameters are adopted by this model.

iscalar

The nuclear spin quantum number $I$.

j_lscalar

The electronic total angular momentum quantum number $J_l$ of the lower state.

j_uscalar

The electronic total angular momentum quantum number $J_u$ of the upper state.

giscalar

The nuclear g-factor $g_I$.

gj_lscalar

The electronic g-factor $g_J$ of the lower state.

gj_uscalar

The electronic g-factor $g_J$ of the upper state.

f_lscalar | None

The total angular momentum quantum number(s) $F_l$ of the lower state to consider. If None, all are considered.

f_uscalar | None

The total angular momentum quantum number(s) $F_u$ of the upper state to consider. If None, all are considered.

qarray_like | None

The polarization vector $\vec{q} = (q_{-1}, q_0, q_1)$ in the helicity basis, or an integer in {-1, 0, 1} for pure $\sigma^-$, $\pi$ or $\sigma^+$ light. If None, all components are equal. The vector is normalized to a sum of 1.

rho_mlIterable[array_like] | None

The lower state populations. Must be an iterable of arrays. If None, the default list is given by rho_ml = [np.ones(2 * f + 1) for f in f_l].

rho_as_parbool

Whether to parameterize the transition intensities by the lower state populations rho(F, m) and the polarization components q(-1), q(0) and q(1) (True) instead of one intensity parameter per transition (False).

scale_par_with_shiftstr | None

Choose a parameter that is scaled with the Zeeman shift such as the Lorentz width "Gamma".

linearbool

Whether the Zeeman shift is linear (True) or nonlinear (False). If nonlinear, the Zeeman shift is calculated numerically, decreasing computing speed.

labelstr | None

A label for the Splitter (isotope / isomer / transition).

fixeslist[fix_type]

linkslist[bool]

Whether the parameters are linked to the parameters with the same name in a Linked model.

modelModel | None

The submodel.

nameslist[str]

The names of the parameters.

A map of the parameter names to their indexes.

The current values of the parameters.

Raises:
ValueError

If q is neither a 3d-vector nor in {-1, 0, 1}.
