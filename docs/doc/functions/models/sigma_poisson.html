--- layout: api title: qspec.models.sigma_poisson ---
qspec.models. sigma_poisson  (  x ,  y ,  y_model ,  *params  )[source]

Poisson uncertainties $\sqrt{y_\mathrm{model}}$ estimated from the model values. Model values smaller than or equal to $1$ get an uncertainty of $1$. Can be passed as sigma_y to qspec.models.fit.

Parameters:
xarray_like

The x data (unused).

yarray_like

The y data (unused).

y_modelarray_like

The model values at the x data.

paramsAny

The model parameters (unused).

Returns:
sigma_yndarray[floating]

The Poisson uncertainties.
