--- layout: api title: qspec.get_f ---
qspec. get_f  (  i ,  j  )[source]

All quantum numbers fulfilling $|I - J| \leq F \leq I + J$, where $F\in\mathbb{N}_0$.

Parameters:
iscalar

The nuclear spin quantum number $I$.

jscalar

The electronic total angular momentum quantum number $J$.

Returns:
F_listlist[quant]

All possible $F$ quantum numbers.
