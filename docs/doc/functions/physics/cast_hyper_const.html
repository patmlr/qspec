qspec. cast_hyper_const  (  hyper_const=None  )[source]

Cast the hyperfine-structure constants to a 3d-vector $(A, B, C)$.

Parameters:
hyper_constarray_like | None

The hyperfine-structure constants $(A, B, C)$. Currently, constants up to the magnetic octupole order are supported. If hyper_const is a scalar, it is assumed to be the constant $A$. Missing orders are 0 (MHz).

Returns:
hyper_constndarray

The hyperfine-structure constants as a 3d-vector.
