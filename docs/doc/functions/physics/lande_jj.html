--- layout: api title: qspec.lande_jj ---
qspec. lande_jj  (  j0 ,  j1 ,  j ,  g0 ,  g1  )[source]

The electronic g-factor of a state with angular momentum $\vec{J} = \vec{J}_0 + \vec{J}_1$

$$ g_J = g_0\frac{J(J + 1) + J_0(J_0 + 1) - J_1(J_1 + 1)}{2J(J + 1)} + g_1\frac{J(J + 1) - J_0(J_0 + 1) + J_1(J_1 + 1)}{2J(J + 1)}. $$
Parameters:
j0scalar

The angular momentum quantum number $J_0$.

j1scalar

The angular momentum quantum number $J_1$.

jscalar

The angular momentum quantum number $J$.

g0scalar

The g-factor $g_{J_0}$.

g1scalar

The g-factor $g_{J_1}$.

Returns:
g_Jfloat

The g-factor $g_J$.
